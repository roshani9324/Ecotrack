# 🌿 EcoTrack – Smart Waste Management Platform

**Smarter Waste Management. Greener Tomorrow.**

EcoTrack is a modern and responsive SaaS platform designed to make waste management smarter, easier, and more efficient. It focuses on smart waste monitoring, efficient collection, and sustainable environmental practices.

## 🚀 Live Demo

**Website:** [https://ecotrack-indol.vercel.app/](https://ecotrack-indol.vercel.app/)

## 📌 About the Project

EcoTrack aims to improve traditional waste management using modern technology. The platform provides an easy-to-understand interface to explore smart waste management solutions and promote cleaner, greener communities.

## ✨ Key Features

- **Modern Landing Page:** Clean and attractive user interface.
- **About EcoTrack:** Introduction to the platform, its mission, and vision.
- **How It Works:** Step-by-step explanation of the waste management process.
- **Smart Monitoring:** Concept for monitoring waste levels and collection needs.
- **Features Section:** Highlights of smart waste management solutions.
- **Pricing Section:** Displays available service plans.
- **Contact Section:** Provides a way for visitors to request information or a demo.
- **Responsive Design:** Designed for desktop, tablet, and mobile devices.

## 💻 Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/roshani9324/Ekotrack.git
```

**2. Navigate to the project folder**

```bash
cd Ekotrack
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌍 Project Objective

The main objective of EcoTrack is to promote smarter waste management practices through technology, improve waste collection efficiency, and contribute towards a cleaner and more sustainable future.

## 🎨 Design Choices & Challenges

1. I chose a green and white color theme to represent nature, sustainability, and environmental awareness.
2. I designed a clean and modern SaaS interface to make the platform attractive and easy to navigate.
3. Clear headings, engaging content, and call-to-action buttons help visitors understand the product.
4. I used reusable React components to maintain a structured and organized codebase.
5. Responsive CSS was implemented to provide a smooth experience across desktop, tablet, and mobile devices.
6. One of the main challenges was creating responsive layouts while maintaining consistent spacing and alignment.
7. I also worked on configuring the Vite project for deployment and ensuring the website loads correctly online.
